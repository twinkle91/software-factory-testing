# Mission: MemoFlow (Team Engineering Notes & Action Tracker)

## What MemoFlow Is

MemoFlow is a fast, simple markdown note-taking and action-item tracker for software teams. Users create markdown notes, tag action items with owners and statuses, filter items, and export selected rows from their active workspace to valid RFC 4180 CSV.

## What MemoFlow Must NEVER Become

Reject issues, pull requests, or requests proposing these out-of-scope features at Intake:
1. No Real-Time Video/Audio Calling or Screen Sharing. This is a written workspace.
2. No Built-In Sprint Velocity Charts, Gantt Timelines, or Burn-Down Dashboards. Do not turn MemoFlow into Jira or MS Project.
3. No Native Email Client or IMAP/SMTP Inbox Sync. Notifications are outbound webhooks only.
4. No Freehand Drawing Canvas / Infinite Whiteboard. Use Markdown notes and action tables.
5. No Custom Scripting Engine or Plugin Marketplace. Keep the app simple and secure.
6. No Cryptocurrency, Billing Ledger, or Invoicing Modules. Financial tracking is out of scope.
7. No Multi-Tenant Custom CSS Theme Builder. The UI follows design.md.
